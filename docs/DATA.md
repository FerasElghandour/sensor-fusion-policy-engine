# Data and artifacts

All runtime experiment inputs are generated by the supplied synthetic sensor and adversarial generators. The two small advisory models train on local synthetic examples. There is no external sensor dataset, remote provider request or pretrained model download in the evaluated path.

Current validation records include every benchmark mission's ground truth, tags and camera ID plus every approach's recorded outcome. These are experiment records, not separate projects. UUID-valued sensor IDs may differ between reproductions; compare deterministic case composition and aggregate outcomes rather than raw file equality across independent runs.

The original `reports/` files are retained historical observations. `validation/discovery-20261016/` records the first expanded run, including the seven stale camera-oracle labels. `validation/local-20261016/` records the corrected run. Do not combine figures from the two runs or describe the generator-label fix as an improvement in enforcement performance.

No live customers, real classified sensor records or operational authorization credentials are included. Redistribution terms for the recovered original source still require review before public release; this document does not assign a license to that material.
