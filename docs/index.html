How it works

Input → Validation → Decision → Evidence

The Python fusion engine executes each synthetic scenario. This page lets you inspect its recorded policy decisions and provenance without exposing an API or requiring credentials.

The release evaluation covers 3,000 synthetic missions. Deterministic association mean F1 is 0.9416; learned association is 0.9298. Generated-case results do not establish operational sensor accuracy or certification.
